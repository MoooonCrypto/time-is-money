# Time Is Money — agent notes

Expo SDK 58 / React Native 0.88 iOS app using the Screen Time APIs. **Read README.md first** (architecture, sources of truth, Mac handoff, verification status), then docs/HANDOFF.md (open tasks, unverified assumptions). Keep docs/HANDOFF.md updated when you finish or add tasks.

Swift can only be built on macOS + Xcode. The cloud container has no Swift toolchain, so use `.github/workflows/ios-ci.yml` (macOS runner: Swift build, TIMCore tests, Maestro UI test). It is manual-only (workflow_dispatch), read-only, and publishes results as an artifact; it never commits to the repo.

## Ground rules
- Expo dev client only (Expo Go cannot load FamilyControls/DeviceActivity).
- Continuous Native Generation: `ios/` is generated (`npx expo prebuild --clean -p ios`) and gitignored. Never edit it by hand; change `app.config.ts`, `config/ids.js`, `targets/*/expo-target.config.js`, `modules/screen-time/**`, or `patches/**`.
- Extensions are generated by `@bacons/apple-targets` from `targets/*`. The DeviceActivityReport type comes from `patches/@bacons+apple-targets+5.0.0.patch` (applied by `postinstall`). If you upgrade apple-targets, re-create the patch.
- Shared Swift lives in `targets/_shared/` (linked into every extension and the app target). `modules/screen-time/ios/Shared/` holds symlinks to it for the Expo module pod. Keep `_shared` free of SwiftUI (monitor/shield extensions are memory-limited).
- The config JSON schema is defined twice: `src/domain/config.ts` (writer) and `targets/_shared/TIMCore.swift` (`TIMConfig`, reader). Change both together; user-facing strings in `src/domain/money.ts` and `TIMCore` must match (tests on both sides).
- Usage durations must stay inside the report extension (never export them to JS or the App Group).
- Dev-only features (`debugShortThresholds`, mock API) must stay gated by `__DEV__` in TS and `#if DEBUG` in Swift.

## Commands
```bash
npx expo install <package>   # use EXPO_OFFLINE=1 if api.expo.dev is unreachable
npm run verify               # typecheck + lint + jest
npm run test:swift-core      # needs a Swift toolchain (macOS)
npx expo prebuild --clean -p ios
npx expo run:ios --device
```
